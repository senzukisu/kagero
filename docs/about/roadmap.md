# Roadmap

## Next

- Kagero Pixel as the default interface font once it is polished
- Drawing tools that stay inside the selection
- Saved custom brushes and a brush library
- A larger plugin API: layers, frames and new tools
- Tilemap mode
- Linux and macOS builds and update packages

| Version | Highlights |
|---------|------------|
| **0.4.3** | Fix for the stripe beside the tool strip; Pixel Cleanup and Color Tools plugins |
| **0.4.2** | Tool strip on an exact grid, a fix for exports that crash, clearer logs, long-session and compatibility tests, app code split by job |
