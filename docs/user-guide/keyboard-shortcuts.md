# Keyboard shortcuts

{% hint style="info" %}
While you type in a text field (layer name, duration, export file name), letters,
arrows, <kbd>Delete</kbd> and <kbd>Ctrl</kbd>+<kbd>A</kbd>/<kbd>C</kbd>/<kbd>X</kbd>/<kbd>V</kbd>/<kbd>Z</kbd>
belong to the text field. Only file shortcuts such as <kbd>Ctrl</kbd>+<kbd>S</kbd> still work.
{% endhint %}

## Files

| Shortcut | Action |
|----------|--------|
| <kbd>Ctrl</kbd>+<kbd>N</kbd> | New image |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | Open |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Save |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> | Save As |
| <kbd>Ctrl</kbd>+<kbd>E</kbd> | Export current frame as PNG |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | Export dialog (images, GIF, sprite sheet) |
| <kbd>Ctrl</kbd>+<kbd>W</kbd> | Close document |
| <kbd>Ctrl</kbd>+<kbd>,</kbd> | Settings |

## Editing

| Shortcut | Action |
|----------|--------|
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Undo |
| <kbd>Ctrl</kbd>+<kbd>Y</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Redo |
| <kbd>X</kbd> | Swap primary and secondary colors |
| <kbd>Esc</kbd> | Cancel the current stroke / stop the preview / deselect |

## Selection

| Shortcut | Action |
|----------|--------|
| <kbd>M</kbd> | Rectangle Select tool |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Select all |
| <kbd>Esc</kbd> | Deselect |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Ctrl</kbd>+<kbd>X</kbd> / <kbd>Ctrl</kbd>+<kbd>V</kbd> | Copy / cut / paste |
| <kbd>Delete</kbd> | Clear the selected pixels |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> | Duplicate the selection (without a selection: duplicate frame) |
| Arrows / <kbd>Shift</kbd>+arrows | Nudge the selected pixels by 1 / 10 px |
| <kbd>Shift</kbd>+<kbd>H</kbd> / <kbd>Shift</kbd>+<kbd>V</kbd> | Flip horizontal / vertical |
| <kbd>Ctrl</kbd>+<kbd>R</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>R</kbd> | Rotate 90° clockwise / counterclockwise |

Flip and rotate apply to the selection, or to the whole active layer when nothing is
selected.

## Layers

| Shortcut | Action |
|----------|--------|
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>N</kbd> | New layer |
| <kbd>F2</kbd> | Rename layer |
| <kbd>Ctrl</kbd>+<kbd>]</kbd> / <kbd>Ctrl</kbd>+<kbd>[</kbd> | Move layer up / down |

## Animation

| Shortcut | Action |
|----------|--------|
| <kbd>Enter</kbd> | Play / stop preview |
| <kbd>,</kbd> or <kbd>←</kbd> | Previous frame (arrows: when nothing is selected) |
| <kbd>.</kbd> or <kbd>→</kbd> | Next frame |
| <kbd>Ctrl</kbd>+<kbd>Home</kbd> | First frame |
| <kbd>Alt</kbd>+<kbd>N</kbd> | New frame |
| <kbd>Alt</kbd>+<kbd>D</kbd> | Duplicate frame |
| <kbd>O</kbd> | Onion skin |
