# Keyboard shortcuts

{% hint style="info" %}
While you type in a text field (layer name, duration), single-letter shortcuts are
ignored so they don't interfere with typing.
{% endhint %}

## Files

| Shortcut | Action |
|----------|--------|
| <kbd>Ctrl</kbd>+<kbd>N</kbd> | New image |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | Open |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Save |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> | Save As |
| <kbd>Ctrl</kbd>+<kbd>E</kbd> | Export current frame as PNG |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | Export all frames as PNGs |
| <kbd>Ctrl</kbd>+<kbd>W</kbd> | Close document |
| <kbd>Ctrl</kbd>+<kbd>,</kbd> | Settings |

## Editing

| Shortcut | Action |
|----------|--------|
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Undo |
| <kbd>Ctrl</kbd>+<kbd>Y</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Redo |
| <kbd>X</kbd> | Swap primary and secondary colors |
| <kbd>Esc</kbd> | Cancel the current stroke / stop the preview |

## Tools

| Shortcut | Tool |
|----------|------|
| <kbd>B</kbd> | Pencil |
| <kbd>E</kbd> | Eraser |
| <kbd>G</kbd> | Fill |
| <kbd>I</kbd> | Eyedropper |
| <kbd>L</kbd> | Line |
| <kbd>U</kbd> | Rectangle |
| <kbd>Shift</kbd>+<kbd>U</kbd> | Filled Rectangle |
| <kbd>H</kbd> or hold <kbd>Space</kbd> | Pan |

## View

| Shortcut | Action |
|----------|--------|
| Mouse wheel, <kbd>+</kbd> / <kbd>-</kbd> | Zoom |
| <kbd>1</kbd> | Actual size |
| <kbd>0</kbd> | Fit to window |
| <kbd>Home</kbd> | Center the canvas |
| <kbd>Ctrl</kbd>+<kbd>G</kbd> | Pixel grid |
| <kbd>F7</kbd> | Timeline |
| <kbd>F8</kbd> | Colors & layers panel |

## Layers

| Shortcut | Action |
|----------|--------|
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>N</kbd> | New layer |
| <kbd>F2</kbd> | Rename layer |
| <kbd>Ctrl</kbd>+<kbd>]</kbd> / <kbd>Ctrl</kbd>+<kbd>[</kbd> | Move layer up / down |

## Animation

| Shortcut | Action |
|----------|--------|
| <kbd>Enter</kbd> | Play / stop preview |
| <kbd>,</kbd> or <kbd>←</kbd> | Previous frame |
| <kbd>.</kbd> or <kbd>→</kbd> | Next frame |
| <kbd>Ctrl</kbd>+<kbd>Home</kbd> | First frame |
| <kbd>Alt</kbd>+<kbd>N</kbd> | New frame |
| <kbd>Alt</kbd>+<kbd>D</kbd> | Duplicate frame |
| <kbd>O</kbd> | Onion skin |
